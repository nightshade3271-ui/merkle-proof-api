RFC 9162 Domain Separation

Protects against second preimage attacks by applying a 0x00 prefix to all leaf nodes and 0x01 to all internal branch hashes.

02

Logarithmic Audit Proofs

Prove that any record belongs to a dataset containing millions of items using only O(log2 N) hashes (~640 bytes for 1M records).

03

Append-Only Consistency

Mathematically prove that updated logs grew strictly in an append-only sequence without historical records being deleted or modified.

REST API Endpoints Overview

Method Endpoint Description
POST /v1/merkle/tree Ingest array of items/hashes and compute root fingerprint
POST /v1/merkle/proof Generate compact O(log N) binary inclusion audit path for specified target
POST /v1/merkle/verify Constant-time verification of an inclusion proof against an expected root
POST /v1/merkle/consistency Generate append-only consistency proof between tree size snapshots
GET /health Cryptographic engine diagnostics, uptime, and RFC specifications
